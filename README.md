# homebrew-pilotdroid

Homebrew tap for [pilotdroid](https://github.com/mofanx/pilotdroid) —
Android automation CLI (persistent device-side agent + binary protocol).

```
brew tap mofanx/pilotdroid
brew install pilotdroid
# or one-shot:
brew install mofanx/pilotdroid/pilotdroid
```

> **Note**: the formula's `sha256` is a placeholder until the v0.6.0
> release assets are published — `brew install` will work once the tag
> lands and the checksum is filled in.
